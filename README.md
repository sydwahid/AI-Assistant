# QuickGPT

QuickGPT is a lightweight Jarvis-inspired AI assistant built for fast and simple conversations.
The project focuses on delivering a clean, responsive, and practical AI experience using modern web technologies and AI integration.

---

## Features

* Fast AI-based conversations
* Clean and responsive UI
* Lightweight and simple design
* Jarvis-inspired assistant experience
* Easy to customize and extend

---

## Tech Stack

* HTML
* CSS
* JavaScript
* AI API Integration

---

## Goal of the Project

The goal of QuickGPT is to create a simple personal AI assistant experience without unnecessary complexity, focusing on speed, usability, and accessibility.

---

## Future Improvements

* Voice assistant support
* Better AI responses
* User authentication
* Chat history
* Mobile optimization
